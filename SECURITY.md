# Security policy

## Supported versions

Iris Gate publishes no versioned releases. The supported line is `main`.

| Version | Supported |
| ------- | --------- |
| `main`  | yes       |

The security model — each control and whether it is implemented — is in [`docs/security.md`](docs/security.md). This repository is a local study stack. Do not treat a control as present unless that document marks it `implemented`.

## Reporting a vulnerability

Report a vulnerability privately through GitHub Security Advisories: [Report a vulnerability](https://github.com/lloliveiradev/iris-gate/security/advisories/new).

Do not report a vulnerability in a public issue, discussion, or pull request. A public report will be closed and redirected to an advisory.
